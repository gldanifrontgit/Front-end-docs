1 · რა არის state

State არის მეხსიერება, რომელსაც React ახსოვს რენდერებს შორის

ორივე მთვლელი ერთსა და იმავეს ცდილობს. მარცხნივ რიცხვი ჩვეულებრივ let ცვლადშია, მარჯვნივ — useState-ში. დააჭირე ორივეს და მერე „სხვა რამემ გამოიწვია re-render“.

setCount ორ რამეს აკეთებს: ინახავს ახალ მნიშვნელობას და React-ს ეუბნება, რომ კომპონენტი ხელახლა დახატოს.

რენდერი ნიშნავს, რომ React კომპონენტის ფუნქციას თავიდან იძახებს. let ცვლადი ყოველ გამოძახებაზე თავიდან იქმნება და 0 ხდება. useState-ის მნიშვნელობა კომპონენტის გარეთ, React-თან ინახება.

3 · State არის კადრი

    
სამჯერ setCount(count + 1) — და მაინც +1

    
ერთი რენდერის განმავლობაში count ფიქსირებული რიცხვია, ფოტოსავით. სამივე გამოძახება ერთსა და იმავე კადრს ხედავს. ფუნქცია c => c + 1 კი წინა შედეგს იღებს.

    შეჯამება
    
    
    ხუთი რამ, რაც state-ზე უნდა გახსოვდეს
    
  
    
  
    
    
    State = React-ის მეხსიერებაინახება რენდერებს შორის. ჩვეულებრივი ცვლადი ყოველ რენდერზე თავიდან იქმნება.
    
    
    setState იწვევს re-render-სReact კომპონენტს თავიდან იძახებს, ადარებს ხეებს და DOM-ში მხოლოდ განსხვავებას ცვლის.
    
    
    State არის კადრიერთ რენდერში count ფიქსირებულია. წინა მნიშვნელობაზე დასაყრდნობად გამოიყენე c => c + 1.
    
    
    ახალი მასივი, ახალი ობიექტიpush-ის ნაცვლად [...arr, x], ობიექტისთვის {...obj, key: v}.
    
    
    Re-render ქვემოთ მიდისკომპონენტთან ერთად ხელახლა იხატება მისი ყველა შვილი.
